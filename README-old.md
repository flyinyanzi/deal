# DEAL? / 一掷千金 V1

纯前端网页小游戏原型，可直接本地打开，也适合部署到 GitHub Pages。

## 文件

- `index.html`
- `style.css`
- `script.js`

## 运行

直接双击 `index.html` 即可。
也可以把整个仓库推到 GitHub，开启 GitHub Pages。

## V1 已实现

- 26 个箱子
- 经典金额结构
- 轮次：6 → 5 → 4 → 3 → 2 → 1 → 1 → 1 → 1
- Banker 报价曲线
- Banker A 型：后期大奖仍在时会提高收购意愿
- 报价人性化取整，不显示过碎数字
- Banker 电话与报价动画
- Deal / No Deal
- Deal 后继续模拟
- 投资者模式：剩余平均价值 / 报价比例 / 风险
- seed 固定同一局
- 今日挑战
- 同局挑战分享链接
- 手机竖屏优先 + 桌面响应式布局

26 箱 + 原版金额结构，人民币显示；轮次严格按 6→5→4→3→2→1→1→1→1。
手机竖屏优先：金额板 → 舞台箱子 → 自己的箱子；PC 自动切横向舞台布局。
Banker A 型：大奖还在时后期会更愿意加价，希望把玩家提前买走。（※1）
报价曲线先用刚才那套 50–60% → 最终 98–110%，再根据局面做小幅修正。（※2）
报价数字做成“有人报出来的数字”，例如计算结果 ¥286,437，不显示 ¥286,437，也不粗暴变成 ¥290,000，而可能得到 ¥286,000 / ¥287,500 / ¥285,000。金额越大，取整粒度也可以越大。
Banker 电话、报价数字跳动、Deal / No Deal、开箱这些关键动画先做出来。
Deal 后继续模拟，让玩家知道“如果刚才没卖会怎样”。
最后有战绩页 + seed 同局挑战链接。
投资者模式先保留入口，显示剩余平均价值、报价比例等，但不替玩家判断 Deal/No Deal。

（※1）
让 Banker 对这种极端局面产生一点反应。
但这里有两种设计哲学。
A类：Banker 害怕大奖
只要百万箱还在，尤其进入后期：
报价略微提高。
他是在说：
“别开了，我现在把你买走。”
这更有节目戏剧性。

B类：Banker 利用你的恐惧
如果残局是：
¥1
¥1,000
¥1,000,000
他反而知道你很可能怕了，于是：
报价压一点。
“你真的敢赌吗？”
这个则更像“Banker 是一个对手”。
