# DEAL? / 一掷千金 V1.1

纯前端网页小游戏原型，可直接本地打开，也适合部署到 GitHub Pages。

## 文件

- `index.html`
- `style.css`
- `script.js`

## 运行

直接双击 `index.html` 即可。
也可以把整个仓库推到 GitHub，开启 GitHub Pages。

## V1 已实现

- 26 个箱子
- 经典金额结构
- 轮次：6 → 5 → 4 → 3 → 2 → 1 → 1 → 1 → 1
- Banker 报价曲线
- Banker A 型：后期大奖仍在时会提高收购意愿
- 报价人性化取整，不显示过碎数字
- Banker 电话与报价动画
- Deal / No Deal
- Deal 后继续模拟
- 投资者模式：剩余平均价值 / 报价比例 / 风险
- seed 固定同一局
- 今日挑战
- 同局挑战分享链接
- 手机竖屏优先 + 桌面响应式布局
